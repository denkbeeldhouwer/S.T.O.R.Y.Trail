# Route

GPX tracks, waypoints, and maps for the 9.5 km trail from Arnhem Centraal to Park Presikhaaf.

The trail runs along the first nine kilometres of an unbroken green corridor that reaches past Apeldoorn. That 80 km is a separate fact, kept here only to show what the city has; it is never the measure of the trail.

Keep the master track as GPX, one waypoint per station, and any printable maps.
